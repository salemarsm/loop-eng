# loop-eng

Plugin do Claude Code para desenvolver um projeto inteiro em **loop**: você afina o requisito até não restar dúvida, aprova o contrato, e os agentes planejam, implementam, revisam e entregam sozinhos — com consenso entre agentes ancorado em testes. Você só injeta (`/loop-eng inject`).

> Em construção. Desenho: [docs/design.md](docs/design.md). Base: Macedo, *Stop Hand-Holding Your Coding Agent* (arXiv:2607.00038).
